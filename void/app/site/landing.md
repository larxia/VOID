# VOID

![VØID, ambient groovebox for the M-VAVE FM-1](manual/img/logo.png "VØID")

VOID is an ambient instrument for the M-VAVE FM-1. The keys play slow drones as chords that follow the note you
press, as add9s, 9ths, minors and 40 more, held one at a time or layered. Around them run a melody sequencer with 24
sounds, a bass that follows your chords or plays your own notes, a drum machine with four kits, a shimmer cloud with
freeze, three LFOs, a tape stage and eight scenes that morph into each other.

![VOID holding a chord: the river of drones and its name, Dm9](manual/img/screen-play.png "VOID on the FM-1's screen")

This is version {{VERSION}}. You install it at your own risk, and the install page can put M-VAVE's own firmware back.

- [Try it in the browser](emu/). It runs the same code as the FM-1, with sound.
- [Install](install/) it from Chrome or Edge, with the FM-1 connected by USB.
- The [Manual](manual/) explains every page, the sequencers and the scenes.
- [Download {{PKG}}](firmware/{{PKG}}) for the command-line installer: `python3 tools/fm1_install.py {{PKG}}`.
